# 🏏IPL 2025 Performance Analytics Dashboard 📈 

# Project Overview

This Power BI project analyzes the performance of players in IPL 2025 through interactive Batting and Bowling dashboards. The dashboard provides insights into player statistics, team performance, tournament highlights, and key performance indicators using data visualization and analytical reporting techniques.

The project aims to transform IPL 2025 statistics into actionable insights through interactive dashboards, helping users explore player performances across batting and bowling categories.

---

**Technologies Used**

- Power BI
- Microsoft Excel
- Power Query
- DAX

---

# Dashboard 1: Batting Analysis

**KPIs**

- Total Runs: 25,166
- Total Fours: 2,245
- Total Sixes: 1,294
- Total Half-Centuries (50s): 143
- Total Centuries (100s): 9

**Features**

- Top 5 Run Scorers of IPL 2025
- Highest Strike Rate Players
- Player-wise Batting Summary Table
- Team-wise and Player-wise Filtering
- Interactive KPI Cards and Visualizations

**Key Insights**

- Sai Sudharsan finished as the highest run scorer with 759 runs.
- Suryakumar Yadav and Virat Kohli were among the leading performers.
- Multiple batters maintained strike rates above 150, demonstrating aggressive scoring.
- Royal Challengers Bengaluru won IPL 2025, while Punjab Kings finished as runners-up.

---

# Dashboard 2: Bowling Analysis

**KPIs**

- Total Wickets: 829
- Total Runs Conceded: 25,250
- Four-Wicket Hauls: 16
- Five-Wicket Hauls: 2
- Average Strike Rate: 23.82

**Features**

- Top 5 Wicket Takers of IPL 2025
- Wickets vs Economy Comparison
- Player-wise Bowling Summary Table
- Team-wise and Player-wise Filtering
- Interactive KPI Cards and Visualizations

**Key Insights**

- Prasidh Krishna emerged as the leading wicket-taker with 25 wickets.
- Noor Ahmad and Josh Hazlewood were among the top-performing bowlers.
- Bowlers with strong economy rates consistently contributed to team success.
- Wicket-taking ability and economy rate played a significant role in match outcomes.

---

**Interactive Features**

- Team-wise filtering
- Player-wise filtering
- Dynamic KPI cards
- Interactive charts and tables
- Cross-filtering between visuals
- Detailed player performance analysis

# Project Objective

The objective of this project is to analyze IPL 2025 batting and bowling performances using Power BI and present meaningful insights through interactive dashboards. The project demonstrates the application of data visualization, KPI reporting, and sports analytics techniques to evaluate player and team performances.
